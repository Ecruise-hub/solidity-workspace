My first Solidity smart contract deployed while learning
smart contract development.

## What I learned
- Solidity contract structure
- State variables
- Functions
- Structs
- Arrays
- Mappings
- Data locations
- Deploying a contract

## Tools
- Solidity
- Remix
- MetaMax wallet
- sepolia eth testnets
- zksync sepolia testnets

## What the contract does
SimpleStorage is a beginner-level Solidity smart contract that demonstrates how to store and retrieve data on the blockchain. It allows users to store a favorite number and add people with their corresponding favorite numbers, using arrays, structs, mappings, and Solidity functions.
